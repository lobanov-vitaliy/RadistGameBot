# RadistGameBot

Telegram-бот для группы по игре [WARDOGS](https://store.steampowered.com/app/1867240/WARDOGS/). Пишет в группу на украинском.

- 🪙 **Курс золота** — каждый день в 00:15 UTC: картинка-график за последние 10 дней и шутка от GPT
- 📰 **Новости, патчи и хотфиксы** из Steam — проверка раз в час, пересказ на украинском через OpenAI
- 🎬 **Популярные YouTube Shorts** про WARDOGS — каждые 15 минут, без повторов

## Запуск

Нужен Node.js 20.12+.

```bash
npm install
cp .env.example .env   # заполнить ключи
npm run dev            # локально, с перезапуском при изменениях
npm run prod           # сборка и запуск через pm2
```

Потом добавить бота в группу: он сам её запомнит и начнёт постить. Порт не нужен — бот работает через long polling. Запускать можно только один экземпляр на токен.

## Переменные окружения

| Переменная | | |
|---|---|---|
| `BOT_TOKEN` | обязательно | токен от @BotFather |
| `OPENAI_API_KEY` | по желанию | пересказ новостей и шутка к курсу; без ключа новости идут оригиналом |
| `OPENAI_MODEL` | по желанию | по умолчанию `gpt-5-mini` |
| `YOUTUBE_API_KEY` | по желанию | YouTube Data API v3; без ключа видео выключены |
| `YOUTUBE_KEYWORDS` | по желанию | что искать, через запятую |
| `GOLD_CRON`, `NEWS_CRON`, `VIDEO_CRON` | по желанию | расписания в UTC |
| `DATA_DIR` | по желанию | где хранить состояние, по умолчанию `data` |

## Команды

Доступны админам группы (в личке с ботом — админу любой из его групп):

- `/gold` — опубликовать курс, если за сегодня ещё не было
- `/news` — проверить новости прямо сейчас
- `/video` — следующее популярное видео
- `/preview` — картинка курса и последняя новость в текущий чат

## Устройство

- `src/index.ts` — бот, команды, расписание, рассылка по группам
- `src/gold.ts`, `src/goldChart.ts` — курс золота и картинка (SVG → PNG)
- `src/news.ts` — новости Steam и их оформление
- `src/youtube.ts` — поиск Shorts
- `src/openai.ts` — запросы к OpenAI
- `src/state.ts` — что уже опубликовано, в `data/state.json`
